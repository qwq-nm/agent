发布门槛

✓管理员与分析员权限隔离；越权 API 全部返回 403，并记录审计。
✓3 个任务并行执行，第 4 个稳定排队；Worker 重启后任务可回收。
✓DeepSeek 只执行 PLAN/CRITIC，GLM 只执行 PARSE/REPORT；生产模式禁用 Mock。
✓模型空响应、坏 JSON、429、5xx、超时和断网均有自动化故障测试。
✓后端核心覆盖率不低于 85%，并通过前端、E2E、安全与数据库迁移测试。
✓真实密钥仅在最终连通性测试前由你写入本机 Secret；日志与 Git 扫描不得命中。
